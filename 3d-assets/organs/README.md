# Organs

Contains individual organ assets.

Examples:

- `heart.glb`
- `lungs.glb`
- `brain.glb`
- `liver.glb`

Rules:

- One organ per file where possible
- Use descriptive lowercase hyphen names
- Prefer `.glb` with Draco/meshopt if needed
- Keep each file under the target budget (optimize before commit)
- Record source/license in `3d-assets/README.md`

No organ models are present yet.
