# NIH Human Reference Atlas

Official candidate source for AnatomiaX whole-body reference models. No GLB has been downloaded or integrated yet.

## Official sources

- NIH 3D: https://3d.nih.gov/
- Human Reference Atlas Portal: https://humanatlas.io/
- HRA documentation: https://docs.humanatlas.io/
- HRA 3D Reference Object Library (collection): https://3d.nih.gov/collections/hra and https://humanatlas.io/3d-reference-library
- PURL base for digital objects: https://purl.humanatlas.io/
- HRA Knowledge Graph: https://lod.humanatlas.io/

- **Model name**: Body, Male — Male-united set
- **Asset/file name**: `hra-reference-organ-united-male-v1.5.glb` (shown as `3d-vh-m-unitedhra-reference-organ-united-male-v1.5.glb` on NIH 3D)

## Why AnatomiaX is using this source

- Expert-reviewed, anatomically correct 3D reference organs developed by specialist medical illustrators and approved by organ experts (HRA SOPs: 3D Reference Object Approval doi:10.5281/zenodo.5944196, Adding 3D Reference Objects doi:10.5281/zenodo.5639651)
- Open-access, CC-BY 4.0, FAIR, from NIH/HuBMAP/HRA — credible for educational medical platform
- Provides unified male and female whole-body sets matching future `3d-assets/male/female` and `systems/organs` structure
- GLB format (binary glTF) lightweight for web, suitable for React Three Fiber
- Used in HRA Portal, Registration User Interface, Exploration User Interface, and Organ Gallery VR — proven for tissue registration and visualization
